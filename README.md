# SQL_Para_Desarrilladores


Este repositorio está diseñado para **compartir las actividades, ejercicios y recursos** del curso **SQL para Desarrolladores**.

## 📚 Contenido del repositorio

- Scripts SQL de práctica
- Consultas en BigQuery
- Actividades evaluadas
- Notas y apuntes importantes

## 🎯 Objetivo

El objetivo de este repositorio es **centralizar todo el material del curso**, de modo que sirva tanto como evidencia de aprendizaje como referencia futura para desarrollos que requieran bases de datos SQL.

## 📌 Tecnologías utilizadas

- **MySQL** para consultas básicas
- **BigQuery** para análisis de datos en la nube
- SQL estándar (DDL, DML, funciones agregadas, subconsultas, etc.)
- Mongo DB
. GitHub
